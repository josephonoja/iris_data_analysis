#  Iris Data Analysis

##  Project Overview

This project analyzes the Iris flower dataset using Python to explore the characteristics of three Iris species through data cleaning, visualization, and interpretation.

The analysis focuses on identifying patterns, comparing flower measurements, and understanding relationships between different flower features.

---

## Objectives

- Clean and prepare the dataset for analysis.
- Explore the distribution of Iris species.
- Compare average flower measurements across species.
- Investigate relationships between flower characteristics.
- Present findings through professional data visualizations.

---

## Tools & Libraries

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook (VS Code)

---

## Dataset

The dataset contains measurements for **150 Iris flowers** from three different species:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

The features analyzed include:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

---

## Visualizations

This project includes:

1. Distribution of Iris Species
2. Average Sepal Length by Species
3. Average Petal Length by Species
4. Average Sepal Width by Species
5. Average Petal Width by Species
6. Distribution of Sepal Length
7. Relationship Between Sepal Length and Petal Length

---

##  Key Findings

- The dataset contains an equal number of samples for each Iris species.
- Iris-virginica generally has the largest petal measurements.
- Iris-setosa has the highest average sepal width.
- Sepal length and petal length show a positive relationship.
- Flower measurements can help distinguish between Iris species.
